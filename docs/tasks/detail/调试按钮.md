> - `sdk_api/dgc_paint_c_api.h:114` —— `dgcSetBrushSetting(ctx, brush, settingId, value)` 参数化设置；`DgcBrushSetting` 枚举当前仅 RADIUS/HARDNESS/OPACITY/RADIUS_LOG 4 项。
> - `sdk_api/dgc_paint_c_api.h:115` —— `dgcSetBrushColor(ctx, brush, r, g, b, a)` 颜色设置（B1-6 已落地）。

## 背景

调试按钮本体在**消费端 UI**（`paint-pc` / `paint-android`）。本线作为 SDK 调试能力的验收宿主纳入任务表（表头「不在本表」的例外）：SDK 侧负责「能力补齐 + 中文注释 + 文档」，消费端负责「按钮接线」，验收为 `paint-pc` 人工验收。

SDK C API **已具备**的能力（本线只验证/接线，不重造）：
- 画布清空：`dgcClear(ctx, r, g, b, a)` —— 带颜色清屏，B2-1 已实现。
- 颜色设置：`dgcSetBrushColor(ctx, brush, r, g, b, a)` —— B1-6 已实现。
- 画笔参数：`dgcSetBrushSetting(ctx, brush, settingId, value)` —— 已实现，但 `DgcBrushSetting` 只覆盖 RADIUS/HARDNESS/OPACITY/RADIUS_LOG 4 项，**stroke modeler 的 9 个参数未暴露**，D6-1 需补齐。

## D6-1 · 画笔参数设置（stroke modeler 参数 + 中文注释）

**目标**：消费端调试面板能实时调整 stroke modeler 的 9 个参数并看到笔迹变化；SDK 侧参数带中文注释。

**产出**

1. `core/stroke_predictor.h` 全部 9 个参数加中文注释（wobble_timeout_ms 抖动消除超时、wobble_speed_floor 抖动消除最低速度、min_output_rate_hz 最小输出采样率、end_of_stroke_stopping_distance_mm 抬笔停止距离、spring_mass_constant 弹簧质量常量、spring_drag_constant 弹簧阻尼常量、kalman_process_noise 卡尔曼过程噪声、kalman_measurement_noise 卡尔曼测量噪声、prediction_interval_ms 预测间隔；措辞以实现为准，须覆盖每个参数的物理/手感含义）。
2. 参数 ↔ `DgcBrushSetting` 映射：`DgcBrushSetting` 枚举**补齐 modeler 参数 settingId**（计划阶段定名与个数，如 `DGC_SETTING_WOBBLE_TIMEOUT_MS` / `DGC_SETTING_SPRING_MASS_CONSTANT` / `DGC_SETTING_PREDICTION_INTERVAL_MS` 等），`dgcSetBrushSetting` 透传到 stroke predictor；**不合法 settingId 返回错误码 + `dgcGetLastError` 描述，不崩溃**。
3. 映射清单文档：参数名 ↔ settingId ↔ 默认值/单位 ↔ 消费端控件建议（滑杆范围）。
4. 消费端（paint-pc）：调试面板每个参数一个滑杆/输入框 → `dgcSetBrushSetting`，改参对新笔画（或实时）生效。

**验收**（paint-pc 人工）

- `stroke_predictor.h` 9 参数均有中文注释。
- 调试面板可调整任意 modeler 参数，且**改参后笔迹明显变化**（如 spring_mass 越小越跟手、prediction_interval 越大预测点越远、wobble_timeout 影响抖动消除），每类参数至少一例人工记录。
- 非法 settingId 返回错误码，不崩溃。
- 未使用调试面板时（默认参数）与现有渲染**零回归**：host `ctest` 全绿（含 B5-3 确定性、B4-1 CPU/GPU 对照）；`android-arm64` preset 仍可编出 `.so`。

**依赖理由**：B3-1（stroke_predictor 内核已落地）、B1-6（`dgcSetBrushSetting` C API 已落地）。

## D6-2 · 画布操作（放大缩小 + 清空）

**目标**：消费端可缩放画布显示、可一键清空画布。

**产出**

1. 放大缩小：实现位置计划阶段定——
   - 优先：**消费端视口变换**（缩放显示读回纹理 + 输入屏幕坐标→画布坐标映射），SDK 不动；
   - 若需 SDK 支持（如画布变换 API）则新增 C API（保持 C ABI 不暴露内部类型、Pimpl 隐藏实现）。
   - 缩放按钮（+ / − / 滚轮 / 重置），缩放下绘制坐标正确。
2. 清空：`dgcClear(ctx, r, g, b, a)` 接线（验证 B2-1 行为 + 消费端按钮 → `dgcClear` + `dgcFlush` + 重新读回显示）。

**验收**（paint-pc 人工）

- 放大后画布像素放大显示清晰（贴图采样正确），缩小后完整可见；**缩放态下画笔落点与光标一致**（坐标映射正确）。
- 清空按钮后画布变为底色（默认白），**无残留笔迹**；清空后仍可继续绘制。
- SDK 侧若新增 C API：host ctest 全绿零回归，`android-arm64` preset 仍可编出 `.so`。

**依赖理由**：B2-1（Vulkan 离屏渲染 + 读回 + `dgcClear` 已落地）。

## D6-3 · 显示控制（颜色设置 + 关闭垂直同步）

**目标**：消费端可切换笔刷颜色、可开关垂直同步。

**产出**

1. 颜色设置：`dgcSetBrushColor(ctx, brush, r, g, b, a)` 接线（验证 B1-6 语义 + 消费端取色器 → 下一笔画用新颜色）。
2. 关闭垂直同步：
   - SDK 侧**出文档说明**「SDK 纯离屏、无 swapchain/present、无 vsync 概念；关闭垂直同步 = 消费端 present 模式切换」，**不改 SDK 离屏渲染路径**；
   - 消费端按钮切换 present 模式（如 GLFW `glfwSwapInterval(0)` / Vulkan presentMode FIFO→IMMEDIATE），切换即时生效。

**验收**（paint-pc 人工）

- 改颜色后，新笔画为该颜色；旧笔迹不变。
- 关闭垂直同步后帧率不再被刷新率锁定（高刷屏实测帧率>刷新率或帧间隔波动，**人工记录**）；重新开启恢复同步。
- SDK 文档注明 vsync 归属；离屏渲染路径零回归（host ctest 全绿）。

**依赖理由**：B1-6（`dgcSetBrushColor` 已落地）、B2-1（离屏渲染/读回已落地）。
