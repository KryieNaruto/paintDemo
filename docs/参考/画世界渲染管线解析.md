# 画世界渲染管线解析（RenderDoc 抓帧逆向）

> **用途**：DGCamp Paint 净室重写的 GPU 渲染/笔刷内核参考。本文档从画世界 App 的 RenderDoc 抓帧 `RenderDoc结果/qqq.rdc`（50MB）逆向还原其实际渲染管线：shader 集合、笔刷 dab 绘制算法、图层合成策略、ARM 硬件特性。所有结论均可回溯到抓帧内的 GLSL 明文源码。
>
> **抓帧元数据**：RenderDoc v1.46 capture · OpenGL ES · Adreno/ARM 平台（含 `gl_LastFragColorARM` / `ARM_SHADER_FRAMEBUFFER_FETCH`）· 59 个 shader 源码块 · 65 个 uniform · 10 个 sampler · 19 个顶点 attribute。
>
> **解析方法说明**：本文基于 `strings` + Python 从抓帧内提取的 GLSL 明文重建语义（能拿到完整 shader 源码与 uniform/attribute 集合，但**拿不到 draw call 序列/资源绑定**——那些是二进制序列化 chunk）。若需 draw call 级还原，可用官方 `renderdoccmd dump`（Linux tarball，纯文件解析、无需 DISPLAY）把抓帧转为 JSON 序列，以本文的 shader 语义作交叉验证。

## 1. 管线总览

画世界是 **OpenGL ES + GLSL 片段着色器**实现的绘画引擎，与 DGCamp 规划中的 Vulkan compute 路线（§4.5）不同，但算法思路高度对应。

```
触控/笔输入
  → 顶点生成（每 dab 一个四边形，携带压力/圆度/纹理坐标）
  → 顶点着色器（变换 + 压力曲线 + 随机 alpha + 空心/圆度预处理）
  → 片段着色器（SDF 覆盖计算 + 纹理采样 + 抖动 + 对比度映射）
  → 画布自混合：
        image2d_use16f == 0 → 直接写 framebuffer（FBO，ARM 帧缓冲自混合）
        image2d_use16f == 1 → imageStore 写 16F 画布纹理（fragment interlock 原子）
        image2d_use16f == 2 → imageStore 写 32F 画布纹理
  → 图层合成/bitblt（多蒙版：选区+图层蒙版+Alpha 锁定 → over 运算）
  → 上屏（含纸纹背景层）
```

**核心洞察**：画世界的画布渲染在**两个层级**发生：
1. **笔刷 dab 直接自混合到画布纹理**（用 `GL_ARB_fragment_shader_interlock` 保证同像素多次写原子串行）——对应 DGCamp 的 `brush_composite.comp` compute 合成，但用的是片段着色器 + interlock 而非 compute shader。
2. **图层级合成**（blit/bitblt）用独立 shader，带多蒙版（选区 `selMask`、图层蒙版 `layerMask`、Alpha 锁定 `lockAlphaTex`）。

## 2. Shader 变体矩阵（编译期特性开关）

抓帧内 `#define` 符号完整揭示画世界 shader 的**特性变体编译**机制（一个统一大 shader，按特性组合编译成不同变体）：

| 宏 | 语义 |
|---|---|
| `SUPPORT_VTF` | 支持顶点纹理拾取（vertex texture fetch） |
| `TMB_BRU` | 纹理混合笔刷（Texture-Mix Brush，`uvTex` + `mixCol`） |
| `ENGINE_0` / `ENGINE_1` | 渲染引擎版本分支（顶点变换算法不同） |
| `TRANSMIT` | 传递随机 alpha 到片段（`varRandAlp`） |
| `USE_MIP_MAP_LOD0` | 笔刷形状纹理 LOD0（不 mipmap） |
| `USE_SHAPE` | 使用笔刷形状纹理 `shapeTex` |
| `IS_SQUARE` | 方形笔刷 |
| `CAL_OUTSIDE_CIRCLE` | 圆外裁剪计算 |
| `HOL_ALP_IND` | 空心笔刷 + 独立 alpha |
| `BLEND_TYPE0` / `TEX_BLEND_TYPE12` | 混合类型（blit 用） |
| `COL_SPA_TRANS` | 色彩空间转换 |
| `SAPTYPE_BELOW2` | 采样类型（下方的采样分支） |
| `NEED_RETURN_BRU` | 需要返回式笔刷 |
| `SAMTEX` | 采样纹理 |
| `FBO_FETCH` | 使用帧缓冲读取（`gl_LastFragColorARM`） |

> **净室重写启示**：DGCamp 的 `brush_composite.comp` 若想覆盖画世界的全部能力，需在 C++ 侧/预编译期实现同类的特性开关（形状类型、混合类型、蒙版组合、精度模式）。

## 3. 笔刷 dab 绘制算法（净室重写核心参考）

这是净室重写 GPU 笔刷内核**最直接可复刻**的部分。以下算法全部从抓帧 GLSL 还原。

### 3.1 顶点着色器：dab 实例化与预处理

每个 dab 由 CPU 生成一个带 4 个顶点的四边形（billboard），顶点属性携带全部笔刷状态：

| 顶点 attribute | 语义 |
|---|---|
| `inPosition.xy` | 四边形角点（世界坐标） |
| `inPosition.z` | **流量（brushFlow）** —— 流量塞在顶点 z 通道 |
| `inPosition.w` | 透明度 |
| `inTexcoord` / `inTexcoord1` | 纹理坐标 / 次级纹理坐标 |
| `pressu` (vec2) | 压力（双通道，含平滑前后） |
| `inRoundness` | 圆度 |
| `inColorHSVRand` | 颜色 + HSV 随机量 |
| `inOpacity` | 不透明度 |
| `halfLineWidth` | **笔刷半径（半线宽）** |
| `isHollow` | 是否空心 |
| `inTexOffset` | 纹理偏移（→ 旋转角） |

顶点着色器关键计算：

```glsl
// 压力曲线（TMB 纹理混合笔刷用 1.5 幂）
Tmb = pow(pressu.x, 1.5);

// 压力平滑
varPressu = vec2(smoothstep(...), pressu.x), pressu.y);

// 圆度下限（防止椭圆过扁）
minRoundness = 1.0 / (4.0 * halfLineWidth);
if (roundness1 < minRoundness) roundness1 = minRoundness;

// 空心笔刷边宽
EdgeWidth = (1.0 - 2.0 * hollowVal1) * halfLineWidth;

// 随机 alpha 抖动（randAlp.x=抖动强度, randAlp.y=下限）
varRandAlp = max(1.0 - randAlp.x * random2(inCent.xy), randAlp.y);

// 纹理旋转角（ENGINE_0：量化到 4 个 90°）
angle = round(4.0 * inTexOffset) * 1.5708;
```

### 3.2 片段着色器：覆盖（coverage）计算

笔刷形状的覆盖计算是**纯 SDF（有向距离场）+ fwidth 抗锯齿**——不依赖几何，逐像素距离判断：

| 形状 | 距离函数 | 抗锯齿 |
|---|---|---|
| 圆形 | `distToCenter = distance(realCoord, vec2(0.5))` | `ww = fwidth(distToCenter); smoothstep` |
| 椭圆（圆度） | `dist = (s-0.5)²/(roundness²) + (t-0.5)²/0.25` | 同上 |
| 方形 | `dist = max(abs(s-0.5), abs(t-0.5)) * 2.0`（L∞ 范数） | 同上 |
| 圆外裁剪 | `distOff = sqrt(dx²+dy²) - renderRadius` | `smoothstep(-ww, ww, distOff)` |

```glsl
// 通用抗锯齿骨架（所有形状共用）：
// 1. 计算到中心的归一化距离
// 2. fwidth 求屏幕空间导数 → 得到像素级边缘宽度
// 3. smoothstep 在 [-ww, ww] 内做抗锯齿过渡
float ww = fwidth(distToCenter);
```

### 3.3 纹理/纸感细节

```glsl
// 形状纹理采样（shapeTex），mipmap 级别按渲染尺寸计算
float calcMipmapLevel(float shapeSize, float rendWidth) {
    float ratio = shapeSize / rendWidth;
    return log2(max(ratio, ...));

// 使用 mipmap LOD0 时直接 LOD0；否则按 calcMipmapLevel 采样

// 纹理混合笔刷（TMB）：uvTex 采样的颜色按 mixCol 混合到笔刷色

```

### 3.4 随机/抖动

```glsl
// 标准 GLSL hash（正弦点积）
float random(vec2 st) {
    return max(0.0, fract(sin(dot(st.xy, vec2(12.9898, 78.233))) * 43758.5453123));
}
float random2(vec2 p) {
    return random(fract(sin(p) * 43758.5453123));
}
// 用途：随机 alpha 分布、喷枪/喷雾笔刷的像素级散布
// 注：DGCamp §4.0.3 确定性的 seed 注入可替换此 RNG 为可复现实现
```

### 3.5 对比度映射

```glsl
// 对比度作用于 alpha 通道（contrast ∈ [-100, 100] 映射到 [0,2] 系数）
float contrast1 = contrast / 100.0;
alpha0 = aaa * (0.5 + (alpha0 - 0.5) * (contrast1 + 1.0)) +
```

## 4. 画布自混合与精度模式（核心架构）

### 4.1 三种画布写入模式（`image2d_use16f`）

这是画世界渲染引擎最重要的架构决策——**画布缓冲精度可配置**：

| `image2d_use16f` | 模式 | 写入目标 | 机制 |
|---|---|---|---|
| `0` | 直接写 FBO | framebuffer | `gl_LastFragColorARM`（ARM 帧缓冲读取）读回原像素自混合，无需 readback |
| `1` | 16F 画布 | `image2d16f` | `imageStore(image2d16f, ivec2(gl_FragCoord.xy), imageOutColor)` |
| `2` | 32F 画布 | `image2d` | `imageStore(image2d, ...)` |

### 4.2 Fragment shader interlock（原子自混合）

```glsl
#extension GL_ARB_fragment_shader_interlock : require
layout(pixel_interlock_ordered) in;
#define BEGIN_FRAGMENT_INTERLOCK() beginInvocationInterlockARB()
// 抓帧中结束宏同时出现 NV/ARB 变体（endInvocationInterlockNV / endInvocationInterlockARB），按平台宏切换
```

**意义**：当多个笔刷 dab（或同一 dab 的多个像素）写入同一画布像素时，interlock 保证**串行化执行**，使 `imageStore` 的读-改-写原子。这让画世界**无需 compute shader 也能实现 dab 自混合到画布纹理**——用片段着色器 + interlock 模拟了 compute 的并行写。

### 4.3 与 DGCamp Vulkan 方案的对照

| 环节 | 画世界（GLES） | DGCamp（Vulkan，§4.5） |
|---|---|---|
| 画布存储 | FBO 或 16F/32F image2D | storage image，常驻 `GENERAL` 布局 |
| dab 合成 | 片段着色器 + fragment interlock | compute shader `brush_composite.comp` |
| 自混合 | `gl_LastFragColorARM` 帧缓冲读取 | `imageLoad` + premultiplied `over` |
| 精度 | 0/16F/32F 三档可选 | rgba8（可扩展） |
| 抗锯齿 | fwidth + smoothstep（SDF） | 未定（可复用 SDF 思路） |
| 纸纹 | `u_texture_paper` + `paper_scale` 背景层 | 未规划（可借鉴） |

> **净室重写建议**：画世界的「片段 shader + interlock」与「compute shader」是同一能力的两条路。DGCamp 走 compute 更符合 Vulkan 习惯；但画世界的 **SDF 覆盖 + fwidth 抗锯齿 + 三档精度** 这套算法骨架值得整体借鉴。

## 5. 图层合成 / bitblt（多蒙版 over）

画世界图层级合成为**独立 shader**，带完整的蒙版链：

### 5.1 合成 uniform 集合

| uniform | 语义 |
|---|---|
| `srcImage` | 源图层纹理 |
| `selMask` | **选区遮罩**（限制合成范围） |
| `layerMask` / `editTex` | **图层蒙版**（黑白灰遮挡） |
| `lockAlphaTex` + `lockAlpha` | **Alpha 锁定**（只画已有点） |
| `reverseMask` / `oneZero` | 蒙版取反 / 全 1 或全 0 兜底 |
| `colTransType` (ivec2) + `srcGamma`/`dstGamma` | 色彩空间转换（`calcColorDepth = 256`） |
| `blitType` (int) | bitblt 类型（合成方式） |
| `opacity` | 图层不透明度 |
| `useBotColor` / `botColor` | 底色参与（underpainting） |
| `mixCol` | 颜色混合开关 |
| `needBorderAA` / `borderAAColor` | 边框抗锯齿 |
| `caa` (vec4) | coverage AA 参数 |

### 5.2 合成数据流

```
srcImage（源）
  × selMask（选区，限制区域）
  × layerMask（图层蒙版，黑白灰）
  × lockAlphaTex（Alpha 锁定，仅已画区域）
  → over 合成到 dst（画布/下层）
  → 参与 colTransType 色彩空间转换
  → opacity 加权
  → needBorderAA / caa 边缘抗锯齿
```

### 5.3 与 DGCamp 需求的映射

DGCamp 需求（`DGCamp Paint工具.md`）明确要求 **Alpha 锁定 / 图层蒙版 / 剪辑蒙版 / 选区**——画世界的这套蒙版链正是这些功能在 GPU 上的实现。净室重写可直接参考其 uniform 设计。

## 6. 纸纹 / 画布背景

```glsl
uniform vec3  paper_bg;      // 纸纹背景色
uniform vec3  paper_col;     // 纸纹前景色
uniform float paper_scale;   // 纸纹缩放
uniform float shadow_percent;// 阴影百分比

```

纸纹作为**画布背景层**渲染，`paper_scale` 控制缩放，`shadow_percent` 控制纹理阴影强度。DGCamp 需求里"默认无纸纹，可切换"对应的就是这套。

## 8. 净室重写参考要点（结论）

1. **SDF 覆盖 + fwidth 抗锯齿**是笔刷渲染的核心数学，直接可移植到 Vulkan compute/fragment。
2. **三档画布精度（FBO / 16F / 32F）**值得纳入 DGCamp 离屏模式（§4.0.5）：16F 是画质与带宽的平衡点。
3. **蒙版链（选区 × 图层蒙版 × Alpha 锁定）**是图层功能的 GPU 基础，与需求文档的 Alpha 锁定/蒙版/剪辑蒙版直接对应。
4. **片段 shader + interlock** vs **compute shader**：DGCamp 走 compute 即可，算法（读-改-写 + over）一致。
5. **随机抖动用可复现 hash**：`random2` 是标准 GLSL hash，可被 DGCamp 的 seed 注入替换（§4.0.3 ReplayRandom）。
