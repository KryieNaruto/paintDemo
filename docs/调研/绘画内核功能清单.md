## 十、性能指标（Performance Targets）

| # | 指标 | 目标值 | 测量方法 | 对标 |
|---|------|--------|----------|------|
| P1 | 端到端延迟（触控→显示） | < 30ms | 高速摄影≥240fps / SurfaceFlinger latency | Procreate 级别 |

| P4 | Stamp 上传耗时 | < 1ms | CPU 打点 | 带宽充足 |

| P6 | 大画布压测（≥2048×2048） | 无崩溃，持续绘制 5 分钟 | 持续压测 | 稳定运行 |
| P7 | 显存泄露 | 0 | AGI 追踪显存 | 显存稳定 |
| P8 | 笔刷大小范围 | 1px ~ 5000px | 边界测试 | 覆盖 Procreate 范围 |

## 十二、功能优先级分组

### 第一梯队 · MVP（必须首批完成）
笔刷引擎（1-6, 13-14, 19-22）+ 画布（31-32, 37-39）+ 图层基本操作（44-48, 50-51, 53）+ 混合模式基础（60-62, 65, 67-68, 70-73）+ 颜色（76-77, 79-80）+ 选区（84, 86, 88, 91）+ 填充（92-93）+ 输入（101-105）+ 渲染（109-118）+ 性能（P1-P7）

笔刷属性（7-12, 15-18, 23-24）+ 图层高级（55-59）+ 混合模式补充（63-64, 66, 69）+ 纸纹（41-43）+ 变换（94-95）+ 滤镜（97-98）

|------|-----------|-----------|-----|---------|
| 笔刷引擎 | libmypaint + GPU 合成 | 自研 GPU 内核 | 成熟 CPU+GPU | OpenGL stamp blit |
| 渲染 API | Vulkan Compute | Metal Compute | OpenGL | OpenGL 4.6 |
| 混合模式 | 21 种 | 20+ 种 | 30+ 种 | 齐全 |
| 最大图层数 | 与显存/画布联动 | 不限（iPad 显存） | 限 RAM | 有限 |
| 笔迹预测 | 速度外推预测 | 前缓冲渲染 | 无 | 有 |
| 色彩空间 | sRGB/P3 | sRGB/P3 | sRGB/CMYK/ICC | sRGB |
| 撤销步数 | 无限（stroke 级） | 无限 | 自定义 | 有限 |
| 端到端延迟 | < 30ms | < 20ms | ~50ms | ~40ms |
| 帧率 | 60fps（120fps） | 120fps | 60fps | 60fps |
