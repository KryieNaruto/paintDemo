> `| G0-1 | 线G-Git | 远端拓扑 + docs/git/ 消费者模板 + scripts/bootstrap-consumer.sh | 执行中 | — | 待审核 |`
> 任务书：`docs/tasks/detail/共同基座.md` §G0-1；技术背景：`DGCPaint_技术规划.md` §9、`docs/调研/路线整理.md` §7（SDK 化 + C API 边界）。

## 目标

写清「本库是 SDK、消费者以 submodule 引用」，给出可复制的消费者模板与 bootstrap 脚本。**不在本任务创建 GitHub 仓库**（本环境 gh 只读），只交文档/模板/脚本。

## 验收标准（抄自 `docs/tasks/detail/共同基座.md` §G0-1「验收」）

- 文档列出待建仓库名与用途；模板 CMake 只链 `dgc_paint`。
- 脚本 `--help` 说明「先自己 `gh repo create` / 网页建空库」。
- 本仓库根目录仍无 `ui/` `app/` 消费者代码。

评审通过必要条件（同任务书「评审打通过的必要条件」行）：
- 拓扑文档 + 两套模板 + bootstrap；submodule 路径 `sdk/`。

## 产出（抄自任务书 §G0-1「产出」与「约定」）

产出：
- `docs/git/README.md`：拓扑（`paintDemo` / `paint-android` / `paint-pc`）。
- `docs/git/templates/paint-android/`、`docs/git/templates/paint-pc/`：README + 示例 CMake（`add_subdirectory(sdk)`）。
- `scripts/bootstrap-consumer.sh`：在**已存在的空克隆**里 `git submodule add` 本仓库到 `sdk/`。

必须写进文档的约定：
- submodule 路径固定 **`sdk/`** → `https://github.com/KryieNaruto/paintDemo.git`。
- 钉 **commit 或 tag**，禁止长期漂浮跟踪 `main`。
- 消费者只 `#include "dgc_paint_c_api.h"`，禁止 include `core/`。
- clone：`git clone --recurse-submodules ...`。

## 步骤

1. 建 `docs/git/README.md`：
   - 说明本仓库是 `dgc_paint` SDK，消费者通过 submodule 引用，路径固定 `sdk/`。
   - 列出待建仓库名与用途：`paintDemo`（本 SDK 仓库，已存在）、`paint-android`（Android UI 消费者，自备 JNI/Compose/Ink）、`paint-pc`（PC UI 消费者，自备 ImGui/GLFW 窗口）。
   - 写死四条约定：`sdk/` → `https://github.com/KryieNaruto/paintDemo.git`；钉 commit/tag 不跟踪 main；只 `#include "dgc_paint_c_api.h"`；`git clone --recurse-submodules`。
   - 明确非范围：消费者仓库不在本仓库创建；`ui/` `app/` `platform/` 代码不进本 SDK 仓库。
2. 建两套模板目录，各含 README + CMakeLists：
   - CMake 只做 `add_subdirectory(sdk)` + `target_link_libraries(<app> PRIVATE dgc_paint)`，不写窗口/输入逻辑，README 注明窗口句柄经 `dgcSetSurface` 传入、JNI/窗口由消费者自备。
3. 写 `scripts/bootstrap-consumer.sh`：
   - 用法说明（`--help`）：在**已存在的空克隆**里执行；未建库时提示先 `gh repo create`（或网页建空库）再跑本脚本。
   - 参数化仓库 URL（默认 `https://github.com/KryieNaruto/paintDemo.git`，可 `--url` 覆盖）与 submodule 路径（固定 `sdk/`）。
   - 核心动作：`git submodule add <url> sdk/`；可选 `--tag/--commit` 参数钉版本（默认提示钉 tag，不跟踪 main）。
   - 只读安全：脚本只操作消费者目录，不碰本 SDK 仓库文件。
4. 自查验收：
   - 确认 `docs/git/README.md` 列出三仓库名与用途。
   - 确认两模板 CMake 只 `add_subdirectory(sdk)` 并只链 `dgc_paint`。
   - 确认 `scripts/bootstrap-consumer.sh --help` 输出含「先自己 gh repo create / 网页建空库」。
   - `find` 确认根目录无 `ui/` `app/`；`git status` 无既有文件被改动。

## 风险与注意

- **URL 分歧**：本仓库 origin 是 SSH `git@github.com:KryieNaruto/paintDemo.git`，而任务书约定 submodule URL 是 HTTPS `https://github.com/KryieNaruto/paintDemo.git`。**以任务书为准**，文档与脚本默认用 HTTPS，脚本保留 `--url` 覆盖。
- **`dgc_paint` target 尚未存在**（E0-3 未完成）：模板 CMake 是静态示例，本任务不做编译验证；验收只做文本/结构检查，不链接 SDK。
- **不新增消费者代码**：本仓库是 SDK，模板只放在 `docs/git/templates/`，不落地 `ui/` `app/` `platform/`。
- **依赖**：无（任务书明确 G0-1 无依赖，可独立验收）。
