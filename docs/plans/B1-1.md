# B1-1 · 内部接口 + Null 桩 实施计划

> 任务线：线1-内部 · 内部类型 + IPaintKernel/IRenderBackend + Null 桩，host 可编译。状态/审核 SOT 见 `docs/tasks/任务线.md`，本计划不改。
> 依据：`docs/tasks/detail/共同基座.md` · B1-1；`DGCPaint_技术规划.md` §4.0、§2.2；`docs/调研/路线整理.md` §7。

## 目标

L4/L5 内部插拔桩立住；对外仍不可见。交付内部共享类型 + 两个抽象接口（`IPaintKernel` / `IRenderBackend`）+ Null 桩；host 可编译。不提供 `IPlatform`、不碰 GLFW、不实现 dab、不创建 VkDevice。

## 验收标准（抄自 `docs/tasks/detail/共同基座.md` · B1-1）

**产出**

- `core/types.h` — StrokePoint / BrushParams / StampData
- `core/interfaces/i_paint_kernel.h`
- `core/interfaces/i_render_backend.h`
- 不提供 `i_platform.h`
- `NullPaintKernel::strokeTo` 返回空 vector。
- `NullRenderBackend` 的 init/composite/present 为空操作。
- **不**实现 dab、不创建 VkDevice。

**验收**

- host 可编译 Null 桩；无 `IPlatform`；无 GLFW。

**评审通过必要条件**（同任务书）：内部接口 + Null 可编译；无 `IPlatform`。

**依赖理由**：E0-1（Null 桩需说明书确定的编译器版本）。

## 接口签名（取自 `DGCPaint_技术规划.md` §4.0）

```cpp
// core/types.h
struct StrokePoint { float x, y, pressure, tilt_x, tilt_y; uint64_t t_us; bool is_predicted; };
struct BrushParams { float radius, hardness, opacity; /* 颜色/纹理按需扩 */ };
struct StampData   { float x, y, radius, hardness, opacity; /* alpha 形状位图 */ };

// core/interfaces/i_paint_kernel.h
class IPaintKernel {
public:
    virtual ~IPaintKernel() = default;
    virtual BrushHandle createBrush(const BrushParams&) = 0;
    virtual void beginStroke(BrushHandle, const StrokePoint&) = 0;
    virtual std::vector<StampData> strokeTo(BrushHandle, const StrokePoint&) = 0;
    virtual void endStroke(BrushHandle) = 0;
};

// core/interfaces/i_render_backend.h
class IRenderBackend {
public:
    virtual ~IRenderBackend() = default;
    virtual void init(PlatformSurface, int w, int h) = 0;
    virtual void resize(int w, int h) = 0;
    virtual void beginFrame() = 0;
    virtual void composite(const std::vector<StampData>&) = 0;
    virtual void clearCanvas() = 0;
    virtual void present() = 0;
    virtual void shutdown() = 0;
};
```

签名中出现的 `BrushHandle`、`PlatformSurface` 在 §4.0 未给定义，本任务落在 `core/types.h`（不引入 `i_platform.h`）：
- `BrushHandle` = 不透明整型句柄（如 `using BrushHandle = std::uint64_t;`），Null 实现返回 0。
- `PlatformSurface` = 不透明原生窗口句柄（如 `using PlatformSurface = void*;`），Null/headless 下 `init` 可接受 `nullptr`（与 B1-4 `dgcSetSurface(nativeWindow==NULL)` 口径一致）。

## 步骤

1. 建 `core/interfaces/`、`core/null/`、`tests/` 目录（不存在则创建）。
2. 写 `core/types.h`：三个共享 struct + `BrushHandle` / `PlatformSurface` 两个不透明类型；`#pragma once`。
3. 写 `core/interfaces/i_paint_kernel.h`、`core/interfaces/i_render_backend.h`：纯虚抽象类，`#include "core/types.h"`，`#include <vector>`、`<cstdint>` 等必要头。
4. 写 `core/null/null_paint_kernel.h/.cpp`：实现 `IPaintKernel`，`strokeTo` 返回空 `std::vector<StampData>{}`，其余空操作。
5. 写 `core/null/null_render_backend.h/.cpp`：实现 `IRenderBackend`，`init`/`composite`/`present` 及其余方法空操作。
6. 写 `tests/compile_null.cpp`：include 两个 Null 桩头，实例化对象，断言 `strokeTo(...).empty()` 为真、调用 `init(nullptr,0,0)`/`composite({})`/`present()` 后 `main` 返回 0。
7. 用「编译策略」一节的单条 `g++` 命令自验 host 编译 + 运行通过。
8. 自检验收：grep 确认无 `IPlatform` / `i_platform.h` / GLFW / VkDevice / dab 实现；未新增任何 `CMakeLists.txt`、`ui/` `platform/` `app/`。

## 风险

- **E0-3 未完成**：本任务不能依赖库目标编译。已在「编译策略」采用最小静态 `g++` 路径，不抢占 E0-3 的 `CMakeLists.txt`；E0-3 落地后把 `core/null/*.cpp` 接入即可，接口头不变。
- **接口签名里的 `BrushHandle` / `PlatformSurface` 无定义**：技术规划 §4.0 引用了这两个类型但未给出定义。本计划落在 `core/types.h`（不透明句柄 + `void*`），不引入 `i_platform.h`；若后续评审要求 `PlatformSurface` 走平台层，属 B1-4/平台线的调整，不改本任务接口语义。
- **Null 桩位置口径**：E0-3 描述「`kernels/`/`render/` 可空占位，无实现时链 Null」。本计划把 Null 桩放 `core/null/`（B1-1 属「内部」且 E0-3 拥有 `kernels/`/`render/` 骨架），执行时可与 E0-3 口径核对；必要时仅移动目录，接口签名不变。
- **C++ 标准口径**：技术规划 §2.3 用 C++20，E0-1 编译器下限 GCC ≥ 11 可满足；编译命令显式 `-std=c++20`，避免依赖机器默认标准。
- **`tests/` 目录归属**：E0-3 会建 `tests/` 骨架，本任务只新增 `compile_null.cpp`，不建 `tests/CMakeLists.txt`，避免与 E0-3 冲突；B5-1 的 `test_c_api_smoke.cpp` 命名不冲突。
