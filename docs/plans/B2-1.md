## 目标

把 `render/` 的 Null 桩替换为真实的 Vulkan 离屏渲染后端 `VkBackend`，实现 `IRenderBackend`：

1. 无窗口（headless）离屏模式：创建 `VkInstance`（不带 surface 扩展）+ 设备 + 离屏 Canvas storage image，无 swapchain，`present()` 在离屏下为 no-op（§4.0.5）。
2. `brush_composite.comp`（§4.5）用 **shaderc 库在代码内**把 GLSL 编译成 SPIR-V（`shaderc_compile_into_spv` / `shaderc.hpp`），构建期**不** shell 调 `glslangValidator`。
3. `composite(stamps)` 批量 dispatch `brush_composite.comp` 把 stamp 合成到离屏 storage image（premultiplied over + 包围盒 dispatch）。
4. `readback(void*)` 走 `vkCmdCopyImageToBuffer` + map 读回 RGBA8；`exportPNG(path)` = readback + `stb_image_write` 编码 PNG。
5. C API 三个 `NOT_IMPLEMENTED` 函数（`dgcSetOffscreenSurface`/`dgcReadbackPixels`/`dgcExportPNG`）改为真实调用后端。

## 验收标准（人工授权派生，非任务书原文）

1. **VkBackend 落地**：`render/vulkan/vk_backend.{h,cpp}` 实现 `IRenderBackend`；离屏模式创建 `VkInstance`（无 surface）、设备、Canvas storage image（usage 含 `STORAGE | SAMPLED | TRANSFER_DST | TRANSFER_SRC`，布局常驻 `VK_IMAGE_LAYOUT_GENERAL`，§4.0.5/§4.4）；不创建 swapchain；离屏下 `present()` 为 no-op。
2. **shader 与编译**：`render/vulkan/brush_composite.comp` 与 §4.5 一致——`local_size 8×8`、set0 binding0 = `rgba8` `image2D u_Canvas`、binding1 = `sampler2D u_Stamp`、push constant `{stampPos, stampSize, opacity, alphaLock}`、premultiplied over、越界/UV 范围裁剪后 `imageStore`。SPIR-V 由 shaderc 库**运行时/代码内**编译生成，不在 CMake 构建期调用 `glslangValidator`/`glslc`。
3. **合成链路**：`composite(std::vector<StampData>)` 对每个 stamp 在其包围盒内 dispatch；**固定 stamp 能在离屏画布上合成出可见笔刷痕迹**（不依赖 `IPaintKernel` 与 `IPlatform`，即 §阶段2 口径）。
4. **读回/导出**：`readback(void*)` 经 `CopyImageToBuffer` + map 输出 RGBA8；`exportPNG(path)` 输出真实 PNG 文件（`stb_image_write`）。
5. **C API 接通**：`dgcSetOffscreenSurface` / `dgcReadbackPixels` / `dgcExportPNG` 在 Vulkan 后端激活时不再返回 `DGC_ERR_NOT_IMPLEMENTED`，而是调用后端并返回 `DGC_OK`；`dgcUndo` 保持 `NOT_IMPLEMENTED`。
6. **测试**：`tests/test_offscreen.cpp` 直接构造 `VkBackend`，`initOffscreen → clearCanvas → composite(固定 stamp) → readback → 断言像素相对底色发生变化 → exportPNG`；host 用 lavapipe 软件光栅 headless 通过 ctest，无需显示服务器、无需 GLFW。

非目标（不在 B2-1）：窗口/swapchain `present` 路径、真实内核 stamp 生成（B3-1）、CLI 同步单线程确定性路径（B5-2）、golden PNG 逐字节一致（B5-3）。

### 2. GLSL 源 + 内嵌

- 建 `render/vulkan/brush_composite.comp`（§4.5 原文，见下）。
- CMake 配置期 `file(READ brush_composite.comp ...)` + `configure_file` 生成 `brush_composite_glsl.h`（`R"GLSL(...)GLSL"` 原始字符串字面量，delimiter `GLSL` 不与源内容冲突），生成的 h 放 build 目录并加入 include path。这样**单一权威源**是 `.comp`，运行时无文件路径依赖。
- 备选（若 configure_file 转义出问题）：直接手写内嵌头 `brush_composite_glsl.h`，注明与 `.comp` 保持同步。

```glsl
#version 450
layout(local_size_x = 8, local_size_y = 8) in;
layout(set = 0, binding = 0, rgba8) uniform image2D u_Canvas;
layout(set = 0, binding = 1) uniform sampler2D  u_Stamp;

layout(push_constant) uniform PC {
    vec2  stampPos;
    vec2  stampSize;
    float opacity;
    float alphaLock;
} pc;

void main() {
    ivec2 c = ivec2(gl_GlobalInvocationID.xy);
    ivec2 sz = imageSize(u_Canvas);
    if (c.x >= sz.x || c.y >= sz.y) return;

    vec2 uv = (vec2(c) - pc.stampPos) / pc.stampSize;
    if (uv.x < 0.0 || uv.x > 1.0 || uv.y < 0.0 || uv.y > 1.0) return;

    vec4 stamp = texture(u_Stamp, uv);
    float a = stamp.a * pc.opacity;
    if (a <= 0.001) return;

    vec4 canvas = imageLoad(u_Canvas, c);
    vec4 outColor = vec4(stamp.rgb * a + canvas.rgb * (1.0 - a),
                         a + canvas.a * (1.0 - a));
    imageStore(u_Canvas, c, outColor);
}
```

### 3. `VkBackend` 实现（`render/vulkan/vk_backend.cpp`）

- **设备/队列**：Vulkan 1.1 baseline；`vkCreateInstance` 无 `VK_KHR_surface`；枚举物理设备选含 `COMPUTE|TRANSFER|GRAPHICS` 的 queue family（lavapipe 单队列即可）；`vkCreateDevice` 只 enable 所需特性（storage image 写入是 core，无需额外 feature）。
- **资源**：
  - Canvas storage image：`VK_FORMAT_R8G8B8A8_UNORM`，usage `STORAGE|SAMPLED|TRANSFER_DST|TRANSFER_SRC`，初态/常驻 `VK_IMAGE_LAYOUT_GENERAL`。
  - Stamp 纹理：`TRANSFER_DST|SAMPLED`，host staging buffer 上传。
  - Staging readback buffer：`HOST_VISIBLE|HOST_COHERENT`（`TRANSFER_DST`）。
  - Descriptor set0：binding0 = storage image，binding1 = combined image sampler；push constant range 覆盖 PC 结构。
  - Compute pipeline：`VkShaderModule` 由 shaderc 产出的 SPIR-V 创建；`local_size 8×8`。
  - Command pool / per-frame command buffer；fence 用于 readback/export 前等待。
- **`initOffscreen(w,h)`**：建上述资源；`supportsOffscreen()` 返回 true。
- **`init(surface,w,h)`**：`surface==nullptr` 时委托 `initOffscreen`（headless 兼容 `dgcSetSurface`）；非空窗口/swapchain 路径本期不做，返回并记录「未实现窗口路径」。
- **`composite(stamps)`**：对每个 `StampData`，按 `radius` 生成 soft-circle 软刷 alpha 位图（`hardness` 控边缘衰减）→ staging 上传到 stamp 纹理 → 以 `stampPos=(x-radius,y-radius)`、`stampSize=(2r,2r)`、`opacity` 填 push constant → 按包围盒 `ceil(size/8)*8` dispatch。这是 B2-1 的占位 stamp；B3-1 落地后由内核产出的 dab 位图替换（届时 `StampData` 可能扩展位图字段）。空 stamps 向量直接 no-op（保证设备未初始化时也安全）。
- **`clearCanvas()`**：`vkCmdClearColorImage` 或 dispatch 清空 storage image 到默认底色（见「风险」第 4 条关于颜色参数）。
- **`present()`**：离屏 no-op。**`resize(w,h)`**：重建 storage image。**`shutdown()`**：`vkDeviceWaitIdle` + 释放资源。
- **线程安全**：`composite/present` 在 engine 渲染线程、`initOffscreen/readback/exportPNG/clearCanvas` 在 C API 线程；内部加 `std::mutex` 包住 GPU 提交与 readback（见「风险」第 3 条）。

### 6. C API 三函数接线

```cpp
int dgcSetOffscreenSurface(DgcContext* ctx, int w, int h) {
    // NULL/负尺寸校验同现有约定
    if (!ctx->backend->supportsOffscreen()) return NOT_IMPLEMENTED;
    ctx->backend->initOffscreen(w, h); ctx->w=w; ctx->h=h; return DGC_OK;
}
int dgcReadbackPixels(DgcContext* ctx, void* rgbaOut) {
    // rgbaOut 非空校验
    if (!ctx->backend->supportsOffscreen()) return NOT_IMPLEMENTED;
    ctx->backend->readback(rgbaOut); return DGC_OK;
}
int dgcExportPNG(DgcContext* ctx, const char* path) {
    if (!ctx->backend->supportsOffscreen()) return NOT_IMPLEMENTED;
    ctx->backend->exportPNG(path); return DGC_OK;
}
```

## 风险与备选

1. **shaderc 库变体坑（人工已点名）**：Ubuntu `libshaderc-dev` 提供 `libshaderc_shared.so` 与静态 `libshaderc.a`。
   - **首选**：链接共享 `libshaderc_shared`（自带 glslang/SPIRV-Tools，无传递依赖问题），经 `pkg-config shaderc`。
   - **坑**：静态 `libshaderc.a` 可能需再链 `libglslang` + SPIRV-Tools 静态库（`libglslang-dev`/`spirv-tools`），链接顺序敏感。
   - **备选 A**：若从源码自建，用 `libshaderc_combined`（单库打包所有依赖，一次链接），头文件仍是 `shaderc/shaderc.hpp`。
   - **备选 B（降级）**：若 shaderc 库整体不可得，改为「SPIR-V 二进制预编译提交」——用 `glslang-tools` 一次性把 `brush_composite.comp` 编成 `brush_composite.spv` 入库，`vkCreateShaderModule` 直接读 spv，跳过 shaderc。此时 shaderc 仅为可选。执行时优先 shaderc 库，卡住才降级，不静默换路。
2. **host 工具链缺失**：当前缺 Vulkan 头 + shaderc + glslang；apt 候选均可用（已核实 `libvulkan-dev` 1.3.275 / `libshaderc-dev` 2023.8 / `glslang-tools` 15.1.0 / `vulkan-tools` 1.3.275）。若无法 `sudo apt`，头文件可从 NDK sysroot 或 `/home/qiansenwei/workspace/Krita_Linux/{deps,build}/usr/include/vulkan/` 手动 include，但 shaderc 库仍缺 → 走备选 B。
3. **engine 渲染线程 vs C API 线程竞态**：`dgcCreate` 会启动 3 线程 engine，渲染线程持续 `composite([])+present()`；离屏三函数在 C API 线程调 `initOffscreen/readback/exportPNG`。VkBackend 内部加 mutex 串行化 GPU 提交/读回；`composite([])` 在设备未初始化时为 no-op。B5-2 的「同步单线程离屏」才彻底消除该竞态，本任务只保证不崩。
4. **`dgcClear` 颜色参数被丢**（B1-4 遗留）：当前 `clearCanvas()` 无参、`dgcClear` 丢弃 RGBA。B2-1 可顺手把 `clearCanvas` 扩为 `clearCanvas(r,g,b,a)`（改接口 + Null + Vk + 一处调用），或保持无参用固定底色。默认保持无参、VkBackend 清成固定不透明底色；扩展颜色为低风险小改，按需取舍。
5. **stamp 无位图**：`StampData` 目前只有 `x,y,radius,hardness,opacity`（无 alpha 位图）。B2-1 在后端内程序化生成软圆 alpha 作为占位 stamp，保证「固定 stamp 合成痕迹」验收成立；B3-1 换真实 dab 位图时替换（可能扩展 `StampData` 字段，接口兼容性到时处理）。
6. **离屏 PNG 确定性**：lavapipe 浮点/合成在不同驱动可能 ±1 LSB（§4.0.3），B2-1 只要求「像素相对底色变化」，不做逐字节 golden（那是 B5-3）。
7. **PUBLIC include 边界**：Vulkan/shaderc 头必须 PRIVATE，`dgc_paint` 的 PUBLIC include 仍只有 `sdk_api/`；不新增 `ui/` `platform/` `app/`。
