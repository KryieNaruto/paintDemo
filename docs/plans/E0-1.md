## 文档结构（拟写入 `docs/env/env-setup.md`）

1. **适用边界**：本 SDK（`libdgc_paint`）编译环境；不含消费者（Compose/GLFW/ImGui/Jetpack Ink/JDK）安装。
2. **依赖分级总表**（贯穿全文的「硬/软」区分）：
   - 硬依赖（缺失则 host 编译必败）：C++ 编译器（`g++`/`gcc` 或 MSVC）、`cmake` ≥ 3.22、`ninja`。
   - 软依赖（缺失仅警告，不阻断）：Vulkan（`libvulkan-dev` / LunarG Vulkan SDK + 驱动）、Android NDK（r27+，建议 r28）、glslc/shaderc 等 —— 因 Null 后端不硬依赖，仅按需提示。
3. **Linux host**（步骤 + 版本下限）：
   - 包：`build-essential cmake ninja-build libvulkan-dev`；cmake ≥ 3.22（host 建议独立装 3.31+）。
   - 探测命令：`which cmake ninja g++`；`cmake --version`、`g++ --version`、`ninja --version`。
   - 补缺：`sudo apt update && sudo apt install ...`。
   - Vulkan/NDK 探测：`vulkaninfo`/`$ANDROID_NDK_HOME` 有则报版本、无则警告。
4. **Windows（VS2026）**（步骤 + 版本下限）：
   - 安装 VS2026 工作负载「使用 C++ 的桌面开发」+「C++ CMake tools」；Ninja 由 VS 自带。
   - 安装 [LunarG Vulkan SDK](https://vulkan.lunarg.com/)（软依赖，跑 Vulkan compute 才需要）。
   - 探测：`cmake --version`、`cl.exe`、`ninja --version`、`glslc --version`。
5. **换机步骤**：`clone`（`git clone git@github.com:KryieNaruto/paintDemo.git`，先配 SSH key）→ 探测（照上表跑命令）→ 补缺（Linux apt / Windows VS installer + SDK Manager）。
6. **明确非必需**：GLFW、JDK、Android Studio GUI、Jetpack Compose、ImGui 均列为「消费者依赖，非本 SDK 必需」，只提示、不要求装。
7. **故障排查**：cmake 版本过低、ninja 缺失、NDK 未配置时 `cmake --preset android-arm64` 的可读报错提示（E0-3 落地的 preset 在无 NDK 时报错可读，本文档给排查口径）。

## 风险

- **版本下限口径漂移**：E0-2 一键脚本 `--check` 需与本文档一致。本任务在文档里先固化探测命令清单，作为 E0-2 的单一事实来源，避免后续脚本与文档两套口径。
- **软/硬依赖边界误判**：把 NDK 或 Vulkan 误标为硬依赖会阻断 Null 后端 host 编译。以「Null 后端不硬依赖」为准，NDK/Vulkan 一律软依赖、仅警告。
- **目录不存在**：`docs/env/` 尚未创建，写文件前先建目录。
- **越界**：不得顺手补 CMake/工程文件或消费者代码，保持纯文档交付。
