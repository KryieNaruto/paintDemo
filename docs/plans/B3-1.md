## 目标

把 `IPaintKernel` 从 Null 桩替换为 `kernels/brush/` 下的真实自研 C++ 笔刷内核，实现路线 E 的 dab 生成主链（§3a：`strokeTo → countDabsTo → 传感器滤波 + 设置映射 → prepareAndDrawDab`），使 `dgcStrokeTo` 经引擎 → 内核产出**非空 StampData**，送入 B2-1 的 Vulkan compute 后离屏画布上出现**可见笔刷痕迹**（含颜色调制）。

具体：

1. `kernels/brush/` 落地 `Brush`（dab 算法主链）+ `BrushKernel : IPaintKernel`（插拔点①实现）。
2. `Brush::strokeTo` 内实现传感器滤波（压力 gain、speed1/2 指数低通、tilt→declination/ascension、direction 距离低通）+ `countDabsTo`（三设置**求和**，非 max）+ 设置响应曲线求值 + `prepareAndDrawDab`（半径/硬度/不透明度/HSV→RGB 颜色调制）。
3. `dgcCreate` 用工厂把默认内核从 `NullPaintKernel` 换成 `BrushKernel`；引擎 `brushLoop` 仍以单个默认笔刷跑通（`BrushKernel::createBrush` 对全零 `BrushParams` 应用默认预设，避免半径 0 产不可见 dab）。
4. `StampData` 从 5 字段扩展 `r/g/b`（straight RGB）与 `softness`，让「颜色调制」真正可见；B2-1 的 `vk_backend` 软圆栅格化改用逐 dab 颜色（不再固定黑）。

## 验收标准（人工授权派生，非任务书原文）

1. **内核落地**：`kernels/brush/brush_kernel.{h,cpp}` 实现 `IPaintKernel`（`createBrush/beginStroke/strokeTo/endStroke` 全真实）；`createBrush` 返回非零 `BrushHandle`，`strokeTo` 对多段输入产出**非空** `std::vector<StampData>`。
2. **算法主链**：`Brush::strokeTo` 内含 `countDabsTo`（`res4 = res1 + res2 + res3` 求和语义，`res4<0 或 NaN` 归 0）+ `prepareAndDrawDab`；传感器滤波按 §3a.1（`pressure*exp(PRESSURE_GAIN_LOG)`、`norm_speed=hypot(dx,dy)/dtime*viewzoom`、speed1/2 指数低通、tilt 转 declination/ascension、direction 距离低通）落地。
3. **颜色调制可见**：`prepareAndDrawDab` 产出的 `StampData` 携带 `r/g/b`（HSV→RGB 调制）与 `hardness/opacity`；`vk_backend` 软圆 stamp 按逐 dab 颜色烘焙，不再固定黑。
4. **离屏可画**：`dgcBeginStroke → 若干 dgcStrokeTo → dgcEndStroke → dgcFlush` 后 `dgcReadbackPixels` 读回的画布相对底色有像素变化（即内核 stamp 经 B2-1 compute 合成出痕迹）。
5. **确定性可测**：内核 RNG 复用 `core/determinism.h` 的 `IRandomSource`；`BrushKernel` 支持注入/重播种，同 seed（或 `ReplayRandom` 同序列）产出的 dab 序列逐字段一致。
6. **测试**：`tests/test_brush_kernel.cpp`（host）覆盖 createBrush 非零句柄、strokeTo 非空、dab 数/半径/不透明度取值范围、同 seed 确定性、传感器滤波结构断言、多轮 create/stroke 无泄漏循环。离屏集成沿用 B2-1 的 `test_offscreen` 或新增 `tests/test_brush_offscreen.cpp`（lavapipe headless，Vulkan 开关守卫）。
7. **SDK 工程约束**（同 B1-8）：`kernels/brush/` 全零裸 `new/delete` 所有权（`make_unique/unique_ptr`）；`Brush`/`BrushKernel` 经典 Pimpl（不透明 `Impl`，对外 ABI 面不暴露内部类型）；`DGCPAIN_SANITIZE=ON` host 构建 ASan/LSan 零泄漏。

非目标（不在 B3-1）：`.myb` 预设解析器 + 打包 mypaint-brushes（`dgcLoadBrushFromMyb` 保持 `NOT_IMPLEMENTED`）；笔刷管理路由（`dgcCreateBrush/dgcSetBrush/dgcDestroyBrush` 保持 `NOT_IMPLEMENTED`，见风险 R4）；libmypaint host oracle 逐位对照（见风险 R2）；纹理 stamp / 椭圆 dab / `lock_alpha` / 预测点重合成；`present` 窗口路径。

## 步骤

### 1. 类型扩展 + 后端接色

1. `core/types.h`：`StampData` 追加 `r,g,b`（默认 0/0/0，兼容旧构造）与 `softness`（默认 0）。
2. `render/vulkan/vk_backend.cpp`：`MakeSoftCircleStamp` 的 RGB 改读 `s.r/s.g/s.b`（旧测试的固定 stamp 若用聚合初始化需补字段，见步骤 5 测试适配）。

### 2. 内核算法落地（`kernels/brush/`）

按 §3a 顺序：

1. `sensors.{h,cpp}`：压力 gain、`norm_speed`、speed1/2 指数低通、tilt→declination/ascension、direction 距离低通。纯函数 + 可单测。
2. `brush_settings.{h,cpp}` + `brush_mapping.{h,cpp}`：`SettingId`/`MappingPoint`/`BrushSetting` + 响应曲线求值（分段线性，slope 默认 0）；速度映射预计算锚点 `fix1_x=45, fix1_y=0.5, fix2_x=45, fix2_dy=0.015`。
3. `color.h`：`hsv_to_rgb_float`。
4. `brush.{h,cpp}`：`Brush` 状态机（`lastX_/lastY_/lastT_`、`PartialDabs`、速度/方向状态）；`countDabsTo`（求和语义）；`prepareAndDrawDab`（opaque clamp、radius=clamp(exp(radius_log))、offset/抖动、HSV→RGB）；`strokeTo` 主循环（`dabsMoved + dabsTodo >= 1` 的插值 + `Flip` 交替 + `rng_->nextUniform()` 推进）。Pimpl，RNG 经 `unique_ptr<IRandomSource>` 持有。
5. `brush_kernel.{h,cpp}`：`createBrush(BrushParams)`——radius≤0/hardness≤0 时套默认预设（radius≈10px、hardness≈0.7、opacity≈1.0），把 `BrushParams` 映射为 `Brush` 的 base settings；`beginStroke` reset 状态 + 首点；`strokeTo` 转发 `Brush::strokeTo`；`endStroke` 收尾（保留小数余量 flush，MVP 可 no-op）。

### 3. 接线（工厂 + C API + seed 贯通）

1. `brush_kernel_factory.{h,cpp}`：`CreateDefaultPaintKernel()`。
2. `dgc_paint_c_api.cpp`：`dgcCreate` 改用工厂；`dgcSetRandomSeed` 增加把 seed 贯通到 `BrushKernel::SetSeed`（下转型，见风险 R5 线程安全说明）。

### 4. 测试

1. `tests/test_brush_kernel.cpp`（host 无条件）：直接构造 `BrushKernel`/`Brush`，注入 `ReplayRandom` 或 `Mt19937Random(固定 seed)`，断言 strokeTo 非空、半径/不透明度取值、同 seed 逐字段一致、传感器滤波结构、多轮 create/stroke 无泄漏。
2. `tests/test_brush_offscreen.cpp`（Vulkan 开）：`BrushKernel` + `VkBackend` 离屏 `initOffscreen → beginStroke → strokeTo×N → endStroke → readback`，断言像素相对底色变化（满足验收 4「送入 vk_composite 可画」）。
3. 适配既有测试：`test_offscreen.cpp` 若用聚合初始化 `StampData`，补 `r/g/b/softness` 字段。

## SDK 工程约束落点（RAII / Pimpl / 零泄漏）

- **所有权设计（谁拥有）**：`BrushKernel::Impl` 经 `std::unordered_map<BrushHandle, std::unique_ptr<Brush>>` 拥有全部笔刷，`BrushKernel` 析构时经 `unique_ptr<Impl>` 自动释放；`Brush::Impl` 由 `unique_ptr<Impl>` 持有；RNG 由 `std::unique_ptr<IRandomSource>` 持有。全程 `make_unique`，无裸 `new/delete` 所有权。
- **Pimpl 边界**：`Brush` 与 `BrushKernel` 均经典 Pimpl（对外仅 `std::unique_ptr<Impl> impl_`，`Impl` 定义留 `.cpp`）；C ABI 面（`sdk_api/`）仍只经 `DgcContext` 不透明句柄 + `IPaintKernel*` 基类指针，不暴露任何 `kernels/brush/` 内部类型（`Brush`/`BrushSettings` 等不进 `dgc_paint_c_api.h`）。
- **泄漏验证方式**：`DGCPAIN_SANITIZE=ON` host 构建（ASan + LSan）跑 `test_brush_kernel` 的 create/stroke/destroy 循环 + 既有 `test_ownership_loop`，CI 断言零泄漏。
