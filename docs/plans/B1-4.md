## 设计

### 1. 头文件 `sdk_api/dgc_paint_c_api.h`（纯 C）

```c
#ifndef DGC_PAINT_C_API_H
#define DGC_PAINT_C_API_H

#include <stdint.h>

#ifdef __cplusplus
extern "C" {
#endif

/* 不透明句柄：定义只在 .cpp 内，头不暴露任何 C++ 符号 */
typedef struct DgcContext DgcContext;
typedef uint64_t DgcBrush;                       /* 0 = DGC_INVALID_BRUSH */
typedef struct { float radius, hardness, opacity; } DgcBrushParams;

#define DGC_INVALID_BRUSH ((DgcBrush)0)

/* 错误码：int 返回函数 0=成功，非 0=失败（可再 dgcGetLastError 读描述） */
typedef enum {
    DGC_OK                = 0,
    DGC_ERR_NULL_CONTEXT  = 1,  /* ctx 为 NULL */
    DGC_ERR_INVALID_ARG   = 2,  /* 非法参数（负尺寸等） */
    DGC_ERR_INVALID_HANDLE= 3,  /* 无效笔刷句柄 */
    DGC_ERR_NOT_IMPLEMENTED=4,  /* 本期未实现（myb 加载等） */
    DGC_ERR_QUEUE_FULL    = 5,  /* 输入队列满（可重试/丢弃） */
} DgcError;

DgcContext* dgcCreate(void);
void        dgcDestroy(DgcContext*);
int         dgcSetSurface(DgcContext*, void* nativeWindow, int w, int h);
int         dgcResize(DgcContext*, int w, int h);
int         dgcBeginStroke(DgcContext*, float x, float y, float pressure, float tiltX, float tiltY);
int         dgcStrokeTo(DgcContext*, float x, float y, float pressure, float tiltX, float tiltY, int isPredicted);
int         dgcEndStroke(DgcContext*);
DgcBrush    dgcCreateBrush(DgcContext*, const DgcBrushParams*);
DgcBrush    dgcLoadBrushFromMyb(DgcContext*, const char* mybJson);
int         dgcDestroyBrush(DgcContext*, DgcBrush);
int         dgcSetBrush(DgcContext*, DgcBrush);
int         dgcRender(DgcContext*);
int         dgcClear(DgcContext*, float r, float g, float b, float a);
const char* dgcGetLastError(void);

#ifdef __cplusplus
}
#endif
#endif
```

要点：
- `extern "C"` 仅对 C++ 生效（`#ifdef __cplusplus` 守卫），C 编译器直接跳过该块，头整体纯 C 可解析。
- 头只依赖 `<stdint.h>`；无 `class`/模板/`std::`/异常，即「无 C++ 符号作为公开 API」。
- `DgcContext` 只前向声明为 opaque struct，定义放在 `.cpp`；消费者无法看见内部 C++ 实现类型。

### 2. 实现 `sdk_api/dgc_paint_c_api.cpp`

内部结构（不暴露）：

```cpp
struct DgcContext {
    IPaintKernel*  kernel;    // 实际 new NullPaintKernel（基类指针，便于 B2-1/B3-1 换桩）
    IRenderBackend* backend;  // 实际 new NullRenderBackend
    Engine*        engine;
    int            w = 0, h = 0;   // 供 headless 校验（可选）
};

// 错误码记录：dgcGetLastError 无 ctx 参数，故用 thread_local
thread_local DgcError g_last_error = DGC_OK;
```

映射表（C API → 内部）：

| C API | 内部调用 | 返回/说明 |
|---|---|---|
| `dgcCreate` | `new NullPaintKernel` + `new NullRenderBackend` + `new Engine(k,b)`，`engine->start()` | `DgcContext*`（失败返回 NULL，但当前无失败路径） |
| `dgcDestroy` | `engine->stop()`，delete engine/backend/kernel，free ctx | — |
| `dgcSetSurface` | `backend->init(nativeWindow, w, h)` | Null 接受 `nativeWindow==NULL`；返回 `DGC_OK` |
| `dgcResize` | `backend->resize(w, h)` | `DGC_OK` |
| `dgcBeginStroke` | 组 `StrokePoint` → `submitInput({BeginStroke, p})` | 满 → `DGC_ERR_QUEUE_FULL` |
| `dgcStrokeTo` | 组 `StrokePoint`，`p.is_predicted = (isPredicted != 0)` → `submitInput({StrokePoint, p})` | 满 → `DGC_ERR_QUEUE_FULL` |
| `dgcEndStroke` | `submitInput({EndStroke, p})` | 满 → `DGC_ERR_QUEUE_FULL` |
| `dgcCreateBrush` | 本期不接线（引擎固定默认笔刷） | 返回 `DGC_INVALID_BRUSH` + `DGC_ERR_NOT_IMPLEMENTED`（见「风险」备选） |
| `dgcLoadBrushFromMyb` | 无 L5，必失败 | 返回 `DGC_INVALID_BRUSH` + `DGC_ERR_NOT_IMPLEMENTED`，`dgcGetLastError` 说明「myb 加载未实现」 |
| `dgcDestroyBrush` | — | `DGC_ERR_NOT_IMPLEMENTED` |
| `dgcSetBrush` | — | `DGC_ERR_NOT_IMPLEMENTED` |
| `dgcRender` | 渲染线程已自主 composite/present，帧触发为 no-op | `DGC_OK`（见「风险」） |
| `dgcClear` | `backend->clearCanvas()`（r/g/b/a 本期 Null 忽略） | `DGC_OK` |
| `dgcGetLastError` | 返回 `thread_local` 描述串（无错误返回 NULL） | — |

要点：
- **统一入口校验**：所有带 `DgcContext*` 的函数先判 `ctx != NULL`，否则设 `DGC_ERR_NULL_CONTEXT` 并返回错误；`dgcStrokeTo` 可顺带校验 `w/h > 0` 之类（可选，Null 下不强求）。
- **错误码记录**：每个 int-returning 函数结束时把 `g_last_error` 置为 `DGC_OK` 或具体码；`dgcGetLastError()` 把码映射为 `const char*` 描述串（`DGC_ERR_NOT_IMPLEMENTED → "not implemented: myb brush loading"` 等），无错误返回 NULL。
- **预测标记**：`isPredicted` 非 0 则 `StrokePoint::is_predicted = true`，直接落到引擎点流（B1-5 predictor 将来消费）。
- **不改 engine/接口**：本文件只调用既有公开/内部方法（`submitInput`、`init/resize/clearCanvas`），不新增 `IPaintKernel`/`IRenderBackend` 方法。

## 风险

- **`dgcCreateBrush` / `dgcSetBrush` / `dgcDestroyBrush` 的接线**：`Engine::brushLoop` 固定 `createBrush(BrushParams{})` 单默认笔刷，无按笔画选笔刷接口。本计划选择「声明存在、运行时返回 `DGC_ERR_NOT_IMPLEMENTED`」，与任务题「未实现项返回错误码」一致，且不触 engine。若评审要求 `dgcCreateBrush` 至少返回可用句柄，备选：ctx 内维护 `uint64_t` 自增句柄计数，`dgcCreateBrush` 返回 `++counter`（非 0），`dgcSetBrush`/`dgcDestroyBrush` 仅校验句柄有效性并记录在 ctx（不影响渲染，因引擎用固定默认笔刷）；该备选需小幅扩展 `DgcContext` 但不改 engine。
- **`dgcRender` 语义**：3 线程引擎下渲染线程已持续 `composite` + `present`，`dgcRender` 在本架构是 no-op（返回 `DGC_OK`）。真实「每帧调一次」的节流/同步在 B1-6（离屏同步路径）/B2-1（真后端）再定，本任务不改渲染线程。
- **`dgcClear` 线程安全**：`clearCanvas` 由 C API 调用线程直调，与渲染线程并发时理论上有竞态；Null 后端全空操作，无实际影响。真实后端（B2-1）需把 clear 也走渲染线程，本任务仅注明不解决。
- **`dgcGetLastError` 的「0 成功」注释**：任务书该行返回类型是 `const char*`，注释「0 成功；非 0 函数失败时可读」指的是 int-returning 函数的成功/失败约定，而非 `dgcGetLastError` 自身返回 0。本计划按「无错误返回 NULL、有错误返回描述串」实现，并在头内注释澄清；若评审期望「成功返回空串而非 NULL」，改一处映射即可。
- **C++ 符号导出**：host-linux Debug 默认全符号可见，内部 `DgcContext` 等 C++ 符号会出现在 `.so` 导出表。验收「无 C++ 符号作为公开 API」按「公开头只含 C 声明、消费者无法调用任何 C++ 符号」满足；若需严格只导出 C 函数，可后续加 `DGC_API`（`__attribute__((visibility("default")))`）+ `CXX_VISIBILITY_PRESET hidden`，本任务留作可选加固。
- **越界**：不得写 `tests/test_c_api_smoke`（B5-1）、不得实现离屏/确定性/撤销/readback（B1-6/B1-7）、不得建 `ui/ platform/ app/`、不得改 `core/engine.*` 或 `core/interfaces/*`。
