## 目标

把 B1-6 已落地的 `dgcSetRandomSeed`/`dgcSetFixedTime`（当前**仅存参**）升级为真实确定性机制：新建内部头 `core/determinism.h`，提供「可 seed 复现的 RNG 抽象 + 固定时间步进」，并把 C API 两个 setter 接到真实机制上，为 B3-1（真实内核 dab 抖动消费 RNG）与 B5-2/B5-3（CLI 同步离屏 + golden 逐字节 diff）铺路。

具体：

1. **`core/determinism.h`（内部，不对外）**：`DeterminismState{seed, fixed_time_us, override_time}`（对齐 §4.0.3 逐字段）+ `IRandomSource` / `Mt19937Random`（可 seed 复现）/ `ReplayRandom`（回放捕获序列，对齐 路线E §3a.5/§6.3）+ `FixedTimeStepper`（固定时间步进）。
2. **C API 接线**：`dgcSetRandomSeed` 从「存 uint64」升级为「重建/重播种注入 RNG」；`dgcSetFixedTime` 从「存 double」升级为「置 override + 固定时间步进」；点提交路径（`dgcBeginStroke`/`dgcStrokeTo`）在 override 时给 `StrokePoint.t_us` 填固定步进值。
3. **所有权**：RNG 用 `std::unique_ptr<IRandomSource>` 持有（RAII，零裸 `new`/`delete`）；`DeterminismState`/`FixedTimeStepper` 为值成员。
4. **C ABI 冻结**：`sdk_api/dgc_paint_c_api.h` 22 函数签名一字不改，只更新函数上方注释（去掉「本期仅存参」）。
5. **单测**：`tests/test_determinism.cpp` 直接测机制确定性（同 seed 同序列 / ReplayRandom 回放 / 固定时间步进），host ctest 全绿。

非目标：不改 `ui/` `platform/` `app/`；不实现真实内核 dab 抖动（B3-1）；不做 golden PNG 逐字节 diff（B5-3）；不改 `IPaintKernel`/`IRenderBackend` 接口签名（B1-1 已冻结）；不引入真实时间戳来源（平台输入层在消费者仓库，本 SDK 无真实时间源）。

## 验收标准（人工授权派生，非任务书原文）

1. **`core/determinism.h` 落地**：`struct DeterminismState { std::uint64_t seed = 0; double fixed_time_us = 0.0; bool override_time = false; }` 与 §4.0.3 逐字段一致；文件位于 `core/` 内部，**不出现在** `sdk_api/dgc_paint_c_api.h`（对外 ABI 不暴露任何内部 C++ 类型）。
2. **RNG 抽象**（对齐 路线E §3a.5/§6.3）：`IRandomSource` 纯虚接口（`nextUniform()` [0,1) / `nextGauss()` 标准正态）；`Mt19937Random : IRandomSource` 用 `std::mt19937_64`（或 `std::mt19937`）＋分布实现、可 `seed()` 重播种，**同 seed 产出同序列**；`ReplayRandom : IRandomSource` 回放捕获的 `std::vector<double>` 序列（测试用，保证与 oracle 逐位一致，与生产 `Mt19937Random` 解耦）。
3. **固定时间步进**：`FixedTimeStepper` 提供 override 语义——override 时每个 `StrokePoint.t_us = n * step_us`（n 每笔画自 `beginStroke` 归零递增），非 override 时 t_us 为 0（无真实时间源）；消除点流速度依赖抖动（§4.0.3「点流 t_us 时间戳」处置行）。
4. **C API 接线**：`dgcSetRandomSeed(ctx, seed)` 把 seed 存入 `DeterminismState` **并**重建/重播种 `impl_->rng`（`std::make_unique<Mt19937Random>(seed)`）；`dgcSetFixedTime(ctx, t_us)` 置 `override_time = true` 并把 `fixed_time_us` 交给 `FixedTimeStepper`；`dgcBeginStroke` 重置步进器、`dgcStrokeTo` 在 override 时用步进器填 `t_us`；两函数返回码语义不变（`NULL_CONTEXT`/`DGC_OK`）。
5. **所有权 / Pimpl**：`DgcContext::Impl` 内 RNG 为 `std::unique_ptr<IRandomSource> rng`，`DeterminismState`/`FixedTimeStepper` 为值成员；全 SDK（`sdk_api`/`core`/`render`）无裸 `new`/`delete` 所有权令牌（`grep` 仅剩 `= delete`）；`DgcContext` 仍为不透明句柄经典 Pimpl，头只 `typedef struct DgcContext DgcContext;`。
6. **C ABI 不变**：`sdk_api/dgc_paint_c_api.h` 与基线 diff 仅函数注释文本（22 函数签名一字不动）；既有 ctest（`compile_null`/`test_ring_buffer`/`test_engine`/`test_c_api_header`/`test_c_api_b1_6`/`test_offscreen`/`test_ownership_loop`）全绿。
7. **单测 `tests/test_determinism.cpp`**：a) 同 seed 两次构造 `Mt19937Random`，连续 N 次 `nextUniform()`/`nextGauss()` 逐值相等；b) 不同 seed 序列至少一处不同；c) `ReplayRandom` 回放给定序列逐值相等；d) `FixedTimeStepper` override 下产出的 t_us 序列为 `0, step, 2*step, …`，非 override 恒 0；e) 经 C API `dgcSetRandomSeed`/`dgcSetFixedTime` 后上下文不崩溃、返回码 OK。该用例 host ctest 通过。
8. **泄漏验证**：`DGCPAIN_SANITIZE=ON`（ASan/LSan）下 `ctest` 零报告（`test_determinism` + 既有 `test_ownership_loop` 覆盖 RNG `unique_ptr` 析构路径）。

## 所有权设计 / Pimpl 边界 / 泄漏验证（SDK 工程约束）

### 所有权

```
DgcContext（不透明句柄，cpp 内定义）
  └─ std::unique_ptr<Impl> impl_
       └─ Impl
            ├─ std::unique_ptr<IPaintKernel>   kernel    （声明序①）
            ├─ std::unique_ptr<IRenderBackend> backend   （声明序②）
            ├─ std::unique_ptr<Engine>         engine    （声明序③）
            ├─ std::unique_ptr<IRandomSource>  rng       （声明序④，B1-7 新增）
            ├─ DeterminismState  determinism            （值成员）
            └─ FixedTimeStepper   time_stepper         （值成员）
```

- `rng` 用 `std::make_unique<Mt19937Random>(seed)` 创建/重建，析构由 `unique_ptr` 自动完成，无裸 `new`/`delete`。
- 成员声明序：`kernel → backend → engine → rng`。`rng` 是纯值型随机源，与线程无交互，声明序不涉及析构顺序敏感点（引擎在 `dgcDestroy` 显式 `stop()` 后才 `impl_.reset()`）。
- `IRandomSource` 虚析构 `= default`，`unique_ptr<IRandomSource>` 经虚析构正确释放派生对象。

### Pimpl 边界

- 头 `sdk_api/dgc_paint_c_api.h` 仅 `typedef struct DgcContext DgcContext;`（不透明，不改）。
- `core/determinism.h` 是**内部头**（`target_include_directories(dgc_paint PRIVATE ${CMAKE_CURRENT_SOURCE_DIR})` 已覆盖），**不加入** PUBLIC include（PUBLIC 仍只有 `sdk_api/`）。`IRandomSource`/`Mt19937Random`/`ReplayRandom`/`DeterminismState` 不进入 C ABI。
- `dgc_paint_c_api.cpp` include `core/determinism.h`，`Impl` 内新增 `rng`/`determinism`/`time_stepper` 均在 cpp 内定义，不暴露。

### 泄漏验证方式

- **静态**：`grep -rnE '\bnew\b|\bdelete\b' --include='*.h' --include='*.cpp' sdk_api render core`，非 `third_party` 仅剩 `= delete`（删拷贝构造），无 `new X`/`delete x` 所有权表达式。
- **动态（ASan/LSan）**：`-DDGCPAIN_SANITIZE=ON` 构建跑 `ctest`，重点 `test_determinism`、`test_ownership_loop`；Null 后端路径 LSan 零报告（RNG 为纯 CPU 对象，无 Vulkan loader 干扰）。
- **压力**：`test_ownership_loop` 多轮 `dgcCreate`（内含 `make_unique<Mt19937Random>`）→ `dgcDestroy` 后进程退出，LSan 汇总零泄漏，证明 RNG 注入/释放无泄漏。

## 步骤

### 1. `core/determinism.h`（header-only）

```cpp
#pragma once
#include <cstdint>
#include <random>
#include <vector>

// §4.0.3 确定性状态：seed 注入内核 RNG；fixed_time_us 覆盖点流 t_us。
struct DeterminismState {
    std::uint64_t seed          = 0;
    double        fixed_time_us = 0.0;
    bool          override_time = false;
};

// 随机源与算法解耦（路线E §3a.5/§6.3）：生产用 Mt19937Random（可 seed 复现），
// 测试用 ReplayRandom（回放 oracle 序列）。二者分离，互不冲突。
class IRandomSource {
public:
    virtual ~IRandomSource() = default;
    virtual double nextUniform() = 0;   // [0,1)
    virtual double nextGauss()   = 0;   // 标准正态
};

class Mt19937Random final : public IRandomSource {
public:
    explicit Mt19937Random(std::uint64_t seed) : gen_(seed) {}
    void seed(std::uint64_t s) { gen_.seed(s); }
    double nextUniform() override { return uni_(gen_); }
    double nextGauss()   override { return gauss_(gen_); }
private:
    std::mt19937_64 gen_;
    std::uniform_real_distribution<double> uni_{0.0, 1.0};
    std::normal_distribution<double> gauss_{0.0, 1.0};
};

class ReplayRandom final : public IRandomSource {
public:
    explicit ReplayRandom(const std::vector<double>& seq) : seq_(seq) {}
    double nextUniform() override { return seq_[i_++]; }
    double nextGauss()   override { return seq_[i_++]; }
private:
    const std::vector<double>& seq_;
    std::size_t i_ = 0;
};

// 固定时间步进：override 时每个点 t_us = n * step_us（每笔画 beginStroke 归零），
// 消除真实时间戳的速度依赖抖动。
class FixedTimeStepper {
public:
    void beginStroke(double step_us, bool override_) {
        step_ = step_us; override_ = override_; n_ = 0;
    }
    std::uint64_t next() {
        if (!override_) return 0;
        return static_cast<std::uint64_t>(n_++ * step_);
    }
private:
    double step_ = 0.0;
    bool override_ = false;
    std::uint64_t n_ = 0;
};
```

> 说明：`std::mt19937_64` 与 §4.0.2 的 `uint64_t seed` 对齐（无 32 位截断）；路线E §3a.5 示例用的 `std::mt19937`(uint32) 是同一思路的旧写法，生产 RNG 只需「同 seed 同序列」，引擎选型是内部细节（逐位复刻 libmypaint 由 `ReplayRandom` 负责，§6.3 已分离）。

### 2. C API 接线（`sdk_api/dgc_paint_c_api.cpp`）

- `#include "core/determinism.h"`。
- `DgcContext::Impl` 增：

std::unique_ptr<IRandomSource> rng;      // RAII 持有；dgcSetRandomSeed 重建/重播种
DeterminismState determinism;            // §4.0.3 值成员

- `dgcCreate`：在 `impl->engine = ...` 前后加 `impl->rng = std::make_unique<Mt19937Random>(0);`（默认 seed 0）。
- `dgcSetRandomSeed`：

```cpp
int dgcSetRandomSeed(DgcContext* ctx, uint64_t seed) {
    if (ctx == nullptr) { g_last_error = DGC_ERR_NULL_CONTEXT; return DGC_ERR_NULL_CONTEXT; }
    ctx->impl_->determinism.seed = seed;
    ctx->impl_->rng = std::make_unique<Mt19937Random>(seed);   // 重建（旧 unique_ptr 自动释放）
    g_last_error = DGC_OK; return DGC_OK;
}
```

- `dgcSetFixedTime`：

```cpp
int dgcSetFixedTime(DgcContext* ctx, double t_us) {
    if (ctx == nullptr) { g_last_error = DGC_ERR_NULL_CONTEXT; return DGC_ERR_NULL_CONTEXT; }
    ctx->impl_->determinism.fixed_time_us = t_us;
    ctx->impl_->determinism.override_time = true;
    g_last_error = DGC_OK; return DGC_OK;
}
```

- `dgcBeginStroke`：末尾（入队成功后，或入队前）`ctx->impl_->time_stepper.beginStroke(ctx->impl_->determinism.fixed_time_us, ctx->impl_->determinism.override_time);`。注意步进器状态与引擎线程解耦：步进器只在此处（C API 线程、入队前）推进，不与引擎三线程共享，无数据竞争。
- `dgcStrokeTo`：把 `StrokePoint p{x, y, pressure, tiltX, tiltY, 0, (isPredicted != 0)}` 的 t_us 字段改为 `ctx->impl_->time_stepper.next()`（override 时给固定步进值，否则 0）。`dgcEndStroke` 不动 t_us（t_us 恒 0）。

> 步进器在 C API 调用线程（外部）推进，先于入队，与 engine 三线程无共享；`fixed_time_us`/`override_time` 只在 setter 写、在 `beginStroke` 读一次快照，本任务不做跨线程并发保障（与 B1-6 存参一致，CLI 同步单线程路径在 B5-2 才彻底消除时序）。

### 4. 单测 `tests/test_determinism.cpp`

```cpp
#include "core/determinism.h"
#include "dgc_paint_c_api.h"
#include <cstdint>
#include <cmath>
#include <vector>
#include <cstdio>

static int failures = 0;
#define CHECK(cond, name) do { if (!(cond)) { std::fprintf(stderr, "FAIL: %s\n", name); ++failures; } } while (0)

int main() {
    // a) 同 seed 同序列
    Mt19937Random a(42), b(42);
    for (int i = 0; i < 1000; ++i) {
        CHECK(a.nextUniform() == b.nextUniform(), "same seed -> same uniform");
        CHECK(a.nextGauss()   == b.nextGauss(),   "same seed -> same gauss");
    }
    // b) 不同 seed 异
    Mt19937Random c(43);
    bool diff = false;
    for (int i = 0; i < 1000 && !diff; ++i) {
        diff = (a.nextUniform() != c.nextUniform());  // 注意 a 已推进 1000，另起 d 更清晰
    }
    // （实现时用两个新实例 d(42)/e(43) 逐值比较，更清晰）
    // c) ReplayRandom 回放
    std::vector<double> seq{0.1, 0.2, 0.3, 0.4};
    ReplayRandom r(seq);
    CHECK(r.nextUniform() == 0.1 && r.nextGauss() == 0.2 && r.nextUniform() == 0.3, "replay order");
    // d) 固定时间步进
    FixedTimeStepper s; s.beginStroke(1000.0, true);
    CHECK(s.next() == 0 && s.next() == 1000 && s.next() == 2000, "fixed step");
    FixedTimeStepper s2; s2.beginStroke(1000.0, false);
    CHECK(s2.next() == 0 && s2.next() == 0, "no override -> 0");
    // e) C API setter 冒烟（机制已在 c) 覆盖，这里只验返回码）
    DgcContext* ctx = dgcCreate();
    CHECK(ctx != nullptr, "dgcCreate non-null");
    CHECK(dgcSetRandomSeed(ctx, 42) == DGC_OK, "setRandomSeed OK");
    CHECK(dgcSetFixedTime(ctx, 1000000.0) == DGC_OK, "setFixedTime OK");
    dgcDestroy(ctx);
    return failures == 0 ? 0 : 1;
}
```

## 风险与备选

1. **验收来源缺失（已声明）**：`docs/tasks/detail/` 无 B1-7 任务书，本计划验收为人工授权派生（依据 §4.0.2/§4.0.3 + 路线整理 §7.3 + 路线E §6.3）。执行前若需正式任务书，先补 detail 章节再回填；否则以本文件为准（同 B1-8/B2-1 先例）。
2. **「固定时间步进」语义二义性**：§4.0.3 用 `fixed_time_us`（覆盖 t_us 依赖）＋ §4.0.2 注释「固定时间戳（微秒）」，但「步进」既可读作「每点同一固定值」也可读作「每点固定增量」。本计划取「每笔画内 n*step 递增」的固定步长语义（消除速度依赖），并把 `beginStroke` 归零作为笔画边界。若审方坚持「每点同一绝对时间戳」，改动极小（`next()` 恒返回 `step_`），执行时一次点选即可，不阻塞机制主体。

   > **执行取向记录（plan-review 建议 2）**：最终落地取「每笔画内 n*step 固定增量」语义——`beginStroke` 归零 n，`next()` 依次返回 `0, step, 2*step, …`；非 override 恒 0。该取向已记入 `core/determinism.h` 的 `FixedTimeStepper` 注释与 `sdk_api/dgc_paint_c_api.h` 的 `dgcSetFixedTime` 注释。
3. **RNG 引擎选型**：`std::mt19937_64`（对齐 `uint64_t seed`）vs 路线E 示例 `std::mt19937`(uint32)。二者都满足「同 seed 同序列」的确定性验收；逐位复刻 libmypaint 由 `ReplayRandom` 负责（§6.3），与生产引擎无关。默认 `mt19937_64`，避免 64→32 截断丢种子信息。
4. **步进器跨线程可见性**：`time_stepper` 只在 C API 调用线程（入队前）推进，`fixed_time_us`/`override_time` 在 setter 写、`beginStroke` 读快照；当前 C API 各函数本就非线程安全（B1-6 口径一致），不新增并发承诺。CLI 同步单线程路径（B5-2）才彻底消除时序。
5. **负 `t_us`**：§4.0.2 注「负值语义未定义，本期仅存参不校验」。接真机制后保留「不校验」口径（负值进 `FixedTimeStepper` 会产出 `n*负值`，`static_cast<uint64_t>` 回绕），或按 `DGC_ERR_INVALID_ARG` 拒绝。默认保留不校验（不破坏既有 `test_c_api_b1_6` 只验 OK 的断言），审方若要求校验再加一行，不影响主机制。
6. **Null 内核下效果不可观测**：`NullPaintKernel::strokeTo` 返回空 vector，`t_us` 不会产出可读回像素。因此 B1-7 的确定性验收以 `core/determinism.h` 的**直接单测**为准（机制正确性），端到端「同脚本同 seed 像素级一致」属 B5-3（golden PNG）。本任务不把「像素一致」列为验收项。
7. **C ABI 头 diff**：第 3 步只改注释，需保证 `git diff` 无签名行变化（22 函数冻结）。若误动签名，`test_c_api_header`（纯 C 解析）会立即暴露。
